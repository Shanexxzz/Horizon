## [Mojo 编程语言正式开源](https://simonwillison.net/2026/Aug/18/mojo-is-now-open-source/) ⭐️ 8.0/10

Modular 已正式将 Mojo 编程语言开源，以 Apache 2.0 许可证发布了编译器和工具链。这紧随上周 Mojo 1.0 的发布，兑现了自 2023 年 5 月以来的承诺。 Mojo 是一种面向 AI 和高性能计算、语法类似 Python 的语言，开源后可让更广泛的社区审查、扩展并围绕它构建工具。这一里程碑可能加速 Mojo 在 GPU 编程和 AI 基础设施中的采用，而 Python 开发者在这些领域常面临性能瓶颈。 Mojo 最初计划成为 Python 的完整超集，但 Modular 在 2025 年 8 月左右调整了这一目标，表示它“不一定会”发展为 Python 超集。Mojo 基于 MLIR 编译器框架，可面向 CPU、GPU、TPU、ASIC 及其他加速器，并支持 SIMD 风格优化。

rss · Simon Willison · 8月18日 21:39

**背景**: Mojo 是 Modular 为 AI 基础设施和异构硬件开发的系统编程语言。它采用类似 Python 的语法，同时融合了静态类型和受 Rust 启发的借用检查器等系统级特性。Apache 2.0 是一种宽松的开源许可证，允许用户自由使用、修改和分发软件及其修改版本，无需担心版税问题。

## [Qwen 3.8 27B 智能指数追平 GPT-5.6 Luna](https://simonwillison.net/2026/Aug/17/qwen-38-27b-scores-52/) ⭐️ 8.0/10

Qwen 3.8 27B 在 Artificial Analysis Intelligence Index 上获得 52 分，与 GPT-5.6 Luna \(max\) 持平，并仅比 GLM-5.2 \(max\) 和 DeepSeek V4 Pro 0813 \(max\) 低 1 分。阿里巴巴 Qwen 实验室于 2026 年 8 月中旬发布了这款基于 Apache 2.0 许可、支持视觉输入的模型。 一个 270 亿参数的开放权重模型能追平大得多的前沿模型，标志着在消费级或单 GPU 硬件上运行强大 LLM 的重大效率突破。这缩小了开源与闭源模型之间的差距，也让开发者与创作者更容易获得先进的推理和视觉能力。 这款 27B 稠密模型比同分竞品小得多：GLM-5.2 约 753B 参数，DeepSeek V4 Pro 0813 约 1.7T 参数，而 GPT-5.6 Luna 的规模未公开，但很可能远大于 27B。Artificial Analysis Intelligence Index 将大约十项评测汇总为 1 到 100 的分数，涵盖编码、科学推理、智能体工具使用和通用知识等。

rss · Simon Willison · 8月17日 23:58

**背景**: Artificial Analysis Intelligence Index 是一个综合指标，通过汇总大约十项独立评测（包括编码、科学推理、智能体工具使用和通用知识）来给模型的“智能程度”打分。Qwen 3.8 27B 是阿里巴巴 Qwen 实验室推出的 Apache 2.0 许可、支持视觉输入的 LLM，其 27B 参数稠密架构可在单张 GPU 上运行（BF16 约需 56GB 显存，FP8 约需 28GB）。如此高的得分表明开放权重模型如今能与大得多的旗舰系统竞争。更大的仅 API 版本 Qwen 3.8-Max 定价为每百万 token 输入 2 美元、输出 6 美元。

hackernews · herbertl · 8月18日 13:22 · [社区讨论](https://news.ycombinator.com/item?id=49345263)

**背景**: 亚马逊的市场最初围绕产品搜索构建，用户评论和相关的商品列表帮助用户找到特定商品。随着时间推移，广告成为该公司的主要收入引擎，激励机制的转变使得赞助位经常挤占自然结果。这种动态在控制消费者入口的平台中很常见，这也是‘亚马逊税’可作为普遍警示案例的原因。

**社区讨论**: Hacker News 上的讨论大体上支持这一批评，许多用户分享了自己对亚马逊搜索结果质量下降的亲身体验，并将购买转向其他商店，包括本地商店和 Etsy。一些评论者认为，相关广告确实能帮助消费者发现替代品；也有人反驳说，任何卖家都并非‘理所当然’地享有销量。总体而言，讨论反映出人们普遍认识到平台搜索如今首先为平台自身的利益服务。

## [数据中心使下风向气温平均升高 0.8°C](https://asmedigitalcollection.asme.org/sustainablebuildings/article/7/2/024501/1233035/Data-Center-Waste-Heat-as-an-Emerging-Urban) ⭐️ 7.0/10

一项发表在 ASME《可持续建筑与城市工程杂志》上的新现场研究测量了数据中心园区周围的空气温度，发现该设施使下风向气温平均升高约 0.8°C，影响范围延伸约 500 米。部分局部温升高达 4°C。 随着 AI 和云计算推动数据中心快速建设，废热正成为重要的城市热源。这些实地测量为局部气候影响提供了具体证据，可为城市规划、环境监管和数据中心选址提供参考。 观测到的温差\(ΔT\)通过比较上风向和下风向空气温度得出；上风向平均温度约为 42.7°C，在下风向园区东部边界附近升至 43.5°C。作者的搜索窗口似乎延伸约 500–1000 米，因此平均 0.8°C 的效应小于标题中的最大值，但局部峰值可能高得多。

hackernews · cwwc · 8月18日 17:24 · [社区讨论](https://news.ycombinator.com/item?id=49349147)

**背景**: 数据中心消耗大量电力，其中大部分能量最终以废热形式释放——这是一种人为热通量。城市微气候研究传统上使用实地测量、风洞建模和 CFD 模拟来评估此类热量对周边环境的影响，而数据中心是城市中增长最快的集中式人为热源之一。这些测量首次在街区尺度上量化了这一影响。
